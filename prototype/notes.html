14.2 Relaxation

Every shortest-path algorithm in this unit is built on one update rule. For an edge from u to v with weight w(u,v), the tentative distance to v is improved whenever going through u is shorter:

The rule never increases a distance, and once a vertex is removed from the queue its distance is final, provided all weights are non-negative.

14.3 The algorithm

for each neighbor v of u:
    alt = d[u] + w(u, v)
    if alt < d[v]:
        d[v] = alt
        prev[v] = u

With a binary heap the running time is O((V + E) log V). Section 14.4 shows why negative weights break the argument above.
